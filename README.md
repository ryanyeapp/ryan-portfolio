# Portfolio

Personal portfolio for Ryan. Open `index.html` in a browser.

## Change the content

- Name, about text, projects, email, and profile links: `index.html`
- Colors and layout: `css/styles.css`
- Menu, project filters, and the contact form: `js/main.js`

## Contact form

Replace `you@example.com` with your real email. Submitting the form opens a draft in the visitor’s email app.

## Publish

Upload this folder to any static host, such as GitHub Pages, Netlify, or a school server.
